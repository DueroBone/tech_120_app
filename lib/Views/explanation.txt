The generated folder contains what is outputted from Figma.
You output the code from Figma as a Widget. You save this code into a file with a name that describes it well.
After taking the raw code from Figma, you 'wrap' the code in a new widget saved in the Manual folder.
If you create a widget that combines multiple smaller widgets, it also goes in the Manual folder.

This process is especially useful in which items are re-used. For example a chat message bubble's code that was generated by Figma can be saved, and then a manually created chat message list widget can use lots of the bubble widgets.
If you want to change the style of the chat messages, you only need to change what is in the generated folder, and then rest of the code uses the updated version everywhere.
