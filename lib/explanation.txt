The generated folder contains what is outputted from Figma.
You output the code from Figma as a Widget. You save this code into a file with a name that describes it well in the Generated folder.
After taking the raw code from Figma, you 'wrap' the code in a new widget saved in the Manual folder.

The Views folder is for a widget that takes over the entire screen, in Figma this is called a frame.
The Components folder is for smaller things, such as a single chat bubble or the basic user profile tray.
Components do not take up the entire screen and are meant to be reused.
If you create a widget (view or component) that combines multiple components, it also goes in the Manual folder.

This process is especially useful in which items are re-used. For example a chat message bubble's code that was generated by Figma can be saved, and then a manually created chat message list widget can use lots of the bubble widgets.
If you want to change the style of the chat messages, you only need to change what is in the generated folder, and then rest of the code uses the updated version everywhere.

This process may have to be changed if we start including pictures or components, as that requires modifying the generated code, and when it gets replaced with an updated version from Figma, all of those links will be reset. This will only be a problem if you all are interested in properly working on the Flutter code. The best option is to just use the Figma generated code as an example and remake it yourselves using normal Flutter code as it will work much better that way.
This process is only a suggestion, and if you have a better way of organizing the code, please let me know.
